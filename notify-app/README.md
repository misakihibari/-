# 通知メモ

メモを登録した時間に、スマホのロック画面・通知センター・バナーへプッシュ通知する Web アプリ(PWA)。
通知をタップするとアプリが開き、詳細を確認できます。通知はスワイプで消すまで残ります。

## 機能
- 通知内容・詳細・ジャンル・日時(年月日時分)を登録 / 編集 / 削除
- 繰り返し: 毎日 / 曜日指定 / ○時間○分おき
- ジャンルは名前・絵文字アイコン・カラーを自由に追加・編集(カラーが通知カードの枠色になる)
- 「日程別」「ジャンル別」で閲覧。通知済みは枠色の 50% 塗り、繰り返しは 70% 塗り

## 起動
```bash
cd notify-app
npm install
npm start        # http://localhost:3000
npm test         # 時刻計算のテスト
```
VAPID 鍵は初回起動時に `data/vapid.json` へ自動生成されます(通知データは `data/db.json`)。
`data/` はサーバーに永続ディスクとして残してください(鍵が変わると既存の購読が無効になります)。

### 環境変数
| 変数 | 説明 |
|---|---|
| `PORT` | 待ち受けポート(既定 3000) |
| `DATA_DIR` | データ保存先(既定 `./data`) |
| `ACCESS_KEY` | 設定すると API にこのキーが必要(インターネットに公開する場合は設定推奨。初回アクセス時に入力を求められます) |
| `VAPID_SUBJECT` | `mailto:あなたのメール` を推奨 |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | 鍵を自前で管理する場合 |

## スマホで使うには
プッシュ通知には **HTTPS** が必須です(`localhost` のみ例外)。常時稼働するサーバー
(Render / Fly.io / VPS など。`ACCESS_KEY` と永続ディスクを設定)に置くか、Cloudflare Tunnel 等で HTTPS 公開してください。
通知は**サーバーが時刻を監視して送信する**ため、サーバーが止まっていると届きません(停止中に過ぎた分は復旧後に1回だけ通知)。

- **Android (Chrome)**: サイトを開き「通知を有効にする」→ 許可。
- **iPhone (iOS 16.4 以降)**: Safari で開き「共有 → ホーム画面に追加」→ **ホーム画面のアイコンから**開いて「通知を有効にする」。
- 画面右上の「通知ON ✓」をタップするとテスト通知が届きます。

## 構成
- `server.js` API と 15 秒ごとのスケジューラ(web-push で送信)
- `lib/schedule.js` 次回通知時刻の計算(タイムゾーン対応)/ `lib/store.js` JSON 保存
- `public/` 画面(`app.js`)、Service Worker(`sw.js`: 通知表示とタップ時の遷移)、`manifest.webmanifest`
- `npm run icons` でアイコン PNG を再生成
