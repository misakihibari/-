# GMOTECH ニュース要約

https://hd.gmotech.jp/news/ を巡回し、全文と要約を年・月タブで閲覧できる静的Webアプリ。

- `python -m newsapp.update --full` 全件取得+要約 / 引数なしは新着のみ(差分)
- `docs/` を開くだけで閲覧可(`python -m http.server -d docs`)。GitHub Pages 等で公開できます
- `.github/workflows/update.yml` が3時間ごとに更新しコミット(= 新着連動)。要約を Claude で行うには Secret `ANTHROPIC_API_KEY` を設定(未設定時は簡易抽出要約)
- 要約は Claude が全文を読んで100〜200文字にまとめます(`ANTHROPIC_API_KEY` 必須。未設定時は本文の抜粋を「本文の抜粋」と明示して表示)。月の要約は記事要約から、年の要約は月の要約から作ります
- 要約だけ作り直す: Actions の「要約だけ作り直す」(AI要約済みの記事は飛ばすので、途中で止まっても再実行で続きから)
- APIキーなしで要約する方法: Claude の対話セッションが `python -m newsapp.manual dump/apply/groups/apply-groups` で記事を読み、100〜200文字の要約を書き込む(新しい年から順に実施、進捗は `status`)
- ⚠ 開発環境から対象サイトに接続できず、HTML解析は実サイトで未検証。初回は `--full` 実行後に件数・日付を確認し、必要なら `newsapp/scrape.py` を調整

# おはなし帳(トーク形式の小説作成アプリ)

`docs/novel/` にある静的Webアプリ。GitHub Pages で `docs/` を公開している場合は `…/novel/` で開けます(ローカルでは `python -m http.server -d docs` → `http://localhost:8000/novel/`)。スマホではホーム画面に追加するとアプリとして使えます。

- ホーム: 「おはなしを書く」「おはなしを読む」タブ、右端 🗑 で削除した作品(元に戻す/完全に削除)
- トーク画面: キャラ選択 → 入力 → ✔ で吹き出し / ＋ → 「余白」「文章作成」(入力中はリアルタイム表示)
- `**文字**` は半分のサイズで表示(✔ の右隣の * ボタン。文字を範囲選択して押すと `**` で囲みます)
- 吹き出し・地の文をタップすると編集/移動/削除。文字サイズは吹き出し・画面文字それぞれ pt で設定
- ⚙️: 画面のカラー、キャラクター作成・一覧(変更は過去の吹き出しすべてに反映)、題名、サブタイトル、枠のカラー、作品を削除
- データは端末のブラウザ(localStorage)に保存されます。ブラウザのデータを消すと作品も消えるので注意
